# Embryo Backup

Embryo Backup is Embryo-Zero's fork of [restic](https://github.com/restic/restic) (55abaa6, commit 55abaa6). It does encrypted, deduplicated backups.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
